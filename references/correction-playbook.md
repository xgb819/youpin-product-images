# 单图反馈修正决策表

用于用户指出“位置不对、被字盖住、角度不同、出现纯色条、接缝、裁切或重复场景”后的返工。目标是把反馈转成最小可验证修改，不依赖聊天中记住某次临时做法。

## 修正层级

按下列顺序选择能解决问题的最低层级；低层级可解决时不得直接跳到扩图或AI重绘。

1. **文字层修正**：错字、字号、字重、对齐、行距、阴影或Logo位置，仅改文字/Logo层；官方模板给定的锚点不因摄影构图临时漂移。
2. **原图重取景**：主体偏上/偏下、文字轻微压图、画面留白不均，先用等比缩放、裁切窗口和x/y偏移调整原图。保持输出尺寸不变，不生成新背景。
3. **换用本款原素材**：当前角度无法同时满足完整主体和安全区时，从本款主图、SKU、详情长图或实拍中换一张完整场景。详情切片先拼接再取图。
4. **局部清理**：只去旧广告文字、箭头、可安全移除的装饰；商品印花、按钮、接口、配件和实物文字受保护。局部修补后放大核对边缘与光影。
5. **定向扩背景**：原素材确实缺少画布时，仅向缺口方向连续扩展当前场景。输出出现直线分界、重复纹理、镜像物件、光影跳变或拼接感即失败，不继续套字。
6. **受控AI重绘/改角度**：只有用户明确选择、或原图完全无法完成指定角度时使用。固定SKU身份、结构、配件数量、按钮、印花方向、颜色和镜头；AI结果不能成为事实证据。

任何层级完成后先查看实际导出图，再进入下一张。不能因为脚本成功或提示词写了“保持一致”就判定外观正确。

## 常见反馈的直接动作

| 用户反馈 | 先做 | 不要先做 | 验收重点 |
|---|---|---|---|
| 产品整体偏下 | 保持文字锚点，原图向上重取景；必要时轻微等比放大以避免露边 | 扩背景、重生场景、移动官方文字模板 | 主体上移且底座/配件仍完整 |
| 产品或角色被标题盖住 | 保持标题模板，原图向下重取景；若下移会露边，先增加最小等比缩放 | 在顶部叠纯色/渐变遮罩，或重画整件产品 | 文字与关键主体不相交，画布仍铺满 |
| 商品被四边裁切 | 减少放大、调整裁切窗、换完整原图 | 继续用`cover`硬裁，或用纯色补空白 | 主机、遥控器、挂环、豆子/配件全部可见 |
| 上下有纯色条、粉色条或棕色块 | 删除旧文字承载条，恢复连续原画面或换源图 | 保留空条等以后写字，或用色块补比例 | 无无意义色带，背景连续 |
| 扩图有断层/直线 | 回退到扩图前版本，优先重取景或换源图；确需扩图则只重做缺口方向 | 用模糊、渐变或贴片掩盖接缝 | 100%查看无接缝、重复纹理和光影突变 |
| 白字重影/投影 | 删除重复文字层、描边、投影和模糊阴影，只保留单层MiSans | 继续加描边增强可读性 | 放大查看只有一套清晰字形 |
| 多张轮播场景重复 | 为每张换成承担不同信息的本款原图 | 只换标题继续复用同一场景 | 主场景、玩法、功能、细节、配置互不重复 |
| 详情模块太短/太高 | 主体模块按1080–1680自然高度；超过1680按语义切片，信息网格按内容自然高度 | 整体缩小塞进1680，或给信息网格补空白 | 切点不穿过主体、文字或卡片 |
| SKU角度不同 | 默认保留真实原图；用户要求同角度时，以一款为机位参考受控生成另一款，并统一摆位参数 | 仅改色冒充另一SKU，或在未授权时重绘商品 | 轮廓/机位/占比一致，SKU身份细节仍正确 |

## `asset.reframe`：不生图的位置修正

场景和轮播清单可用 `asset.reframe` 记录确定性的等比放大与位置偏移：

```json
{
  "asset": {
    "file": "carousel-02-master.png",
    "origin": "user",
    "subject_boxes": [{"x": 210, "y": 330, "width": 700, "height": 590}],
    "reframe": {"zoom": 1.08, "offset_y": 35}
  }
}
```

- `zoom`为在常规cover基础上的等比倍率，范围1–2。
- `offset_x`正值使原图内容向右移动，`offset_y`正值使内容向下移动；负值反向。
- 偏移会露出画布边缘时渲染器拒绝导出；增加最小必要zoom或减小偏移，不能用纯色填边。
- `subject_boxes`随同一变换更新，并继续接受安全区和文字相交检查。
- 报告记录实际reframe参数；位置反馈只改这些参数和revision，不重编无关图片。

## 同角度SKU的受控AI核对

用户明确要求不同颜色/主题SKU共用角度时，同时提供：一张机位参考和一张目标SKU身份参考。提示词只允许改变相机视角与摆位，不允许把参考SKU的角色、底座色、按钮或配件复制给目标SKU。

导出前逐项比对：

- 同一相机方位、俯视程度、轮廓占比和画布中心；
- 目标SKU的底座色、角色种类、按钮造型、挂环、接口、印花与配件数量；
- 透明背景，无投影、无文字；800×800，alpha主体框在中央640×640内，文件≤300000 bytes；
- 两款可共用摆位参数，但分别保留来源与AI修改记录。相同alpha框只证明摆位，不证明外观一致。

任一身份细节不确定时停止该SKU，回到原图方案或请用户核对；不能靠继续批量生成碰运气。

## 修正后的最小验收

1. 对比上一版，只列本次改变的图ID、参数和原因；未改图用哈希确认保持不变。
2. 以100%查看文字边缘、商品四边、扩展区域和旧字清理区域。
3. 轮播检查1080×1080、<200000 bytes、标题锚点、30px标题/描述间距、顶部194与底部108覆盖区。
4. SKU检查800×800透明PNG、≤300000 bytes、alpha安全区和SKU身份。
5. 详情检查单图≤1680px；主体模块与信息汇总模块分别按自身高度规则，不混用。
6. 失败只返工当前图及其共用母图消费者，不重新生成整套。
